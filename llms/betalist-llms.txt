# BetaList

> BetaList is a startup-discovery platform founded in 2010 that publishes pre-launch and
> recently launched internet startups to a website and a daily newsletter. It operates a
> small read-only REST API over that directory — startups, regions and markets — at
> https://api.betalist.com/v1. Documentation is a public GitHub gist maintained by
> founder Marc Kohlbrugge and linked from the BetaList support page; access tokens are
> granted case-by-case on request, not self-service.

This file was generated by API Evangelist from publicly reachable BetaList material.
BetaList does not publish an llms.txt of its own (https://betalist.com/llms.txt → 404).

## API

- [BetaList API documentation](https://gist.github.com/marckohlbrugge/5a29bf1ba628bb4ca960): the only API reference BetaList publishes. Base URL https://api.betalist.com/v1.
- [Request an API token](https://marc.typeform.com/to/KOdlOu): the token request form named in the documentation.
- [Support & FAQ — "How do I get access to the BetaList API?"](https://betalist.com/support): access is granted case-by-case; the request must state intended use, use case and estimated request volume.

Documented endpoints (all GET, all requiring `?access_token=`):

- `GET /v1/startups` — list startups. Params: `per_page` (max 100), `page`, `region_id`, `market_id`.
- `GET /v1/startups/{id}` — one startup.
- `GET /v1/regions` — list regions. Params: `per_page` (max 500), `page`.
- `GET /v1/region/{id}` — one region (singular path, as published).
- `GET /v1/markets` — list markets. Params: `per_page` (max 500), `page`. Markets form a directed acyclic graph.

No OpenAPI, AsyncAPI, GraphQL SDL, MCP server or agent card is published; unauthenticated
calls to the documented routes return 401 and undefined paths return 404.
