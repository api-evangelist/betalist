JSON Mapper lets you map and transform JSON data between formats right in your browser. Paste example source and target JSONs to auto-generate links by matching paths, values, and keys, then refine them in a manual editor to build a reusable transformation map. Apply the map to real data, save outputs, and with a subscription, save and load maps.
