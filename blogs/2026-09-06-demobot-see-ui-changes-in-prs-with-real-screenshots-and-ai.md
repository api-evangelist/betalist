DemoBot captures visual changes from your code and posts them directly in pull request comments. It runs the branch, detects your framework, builds the app, and takes real screenshots of affected views so reviewers can verify UI changes without local checkout or hunting through preview deploys. It also generates a plain-English summary of what changed and why.
